# AutoCAD Masterclass

A hands-on, two-day AutoCAD course: set up drawings, draw and modify 2D geometry, organise drawings with layers, blocks and external references, then dimension, annotate and plot production-ready technical drawings.

## About the course

Technical drawings communicate a design's exact geometry, sizes and finishes for manufacture or construction. This course takes you from the AutoCAD interface to a plotted, dimensioned drawing sheet. Every topic is followed by hands-on labs built on real practice drawings (DWG), so you finish each topic having produced the drawing yourself.

## Learning outcomes

On completion of this course, you will be able to:

- Read and visualize AutoCAD technical drawings
- Produce 2D and 3D technical drawings using AutoCAD
- Create part lists using AutoCAD
- Create AutoCAD design documentation
- Produce design specification using AutoCAD

## Topics covered

| Day | Topic | What you cover |
|---|---|---|
| 1 | **Topic 1 — Getting Started with AutoCAD** | User interface, workspaces, model and paper space, navigation, precision drafting aids, units |
| 1 | **Topic 2 — Technical Drawing with AutoCAD** | Lines and coordinates, circles, rectangles, polygons, arcs, polylines, ellipses, splines, construction geometry, 2D isometric drawing |
| 1 | **Topic 3 — Modifying Objects** | Move, copy, rotate, offset, mirror, stretch, scale, trim, extend, fillet, chamfer, arrays |
| 2 | **Topic 4 — Organizing Objects** | Object properties, layers, grips, hide and isolate, blocks, attributes, external references |
| 2 | **Topic 5 — Design Documentation** | Text styles, dimensions, multileaders, tables and part lists, hatching, layouts, viewports and plotting |
